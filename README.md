# 刷题小助手 v2

适用于 `Ryanisoda/Ryanisoda.github.io` 仓库根目录的完整静态网站。

## 直接上传

1. 解压本包，将里面的index.html、assets、data、docs等全部内容上传到仓库根目录。不要上传ZIP本身，也不要再套一层文件夹。
2. 已有站点请覆盖新版同名文件。旧版 `data/bank.js` 不再被引用，可以移除；旧的assets/app.js和index.html必须一起更新。
3. 仓库Settings → Pages → Deploy from a branch，选择上传分支（通常main）和/(root)，保存。已有相同设置无需重设。
4. 部署完成后访问 https://ryanisoda.github.io/ 。如果仍显示旧界面，强制刷新。

无需安装依赖、运行npm、构建或配置接口。index.html使用相对资源路径，直接双击也能预览。正式使用建议保持同一个HTTPS网址，以便学习记录持续保存在同一来源中。

## 本次功能

- 快刷：单选选择后或多选提交后，正确立即下一题；错误留在当前题，手动继续。
- 顶部课程下拉菜单。章节、搜索、错题、统计、标记、练习设置按课程分开。
- 统一题库格式1.0，所有题的答案统一为数组，启动时自动校验。
- 支持A1/A2/A3/A4/B/X，X型先勾选后提交，全部选对才算正确；选项乱序后仍按正确内容判分。
- 章节变化时，六种题型的计数实时变化；不改变用户的题型勾选。
- 同一来源下旧版预防医学记录自动迁移一次，原数据键保留。

## 内容与模板

预防医学课程有原有867题，原答案未改动；绪论第88题的五个残缺选项已按原PDF补全。此前审校发现的答案差异未直接替换，参见原校对报告。

菜单另有“格式示例（非医学题库）”，含8道题，其中2道X型题，用于立即体验多选流程、作为新增课程参考。该课程记录独立，预防医学的题数不含这些示例。原PDF中225道X型题尚未加入，因此预防医学X型计数为0。

完整格式及新增课程步骤见 [题库格式指南](docs/QUESTION_BANK_FORMAT.md)。可复制templates/new-course.js创建新课程；纯JSON版本为templates/new-course.json。

## 维护校验

有Node.js时，在解压目录运行：

```bash
node tools/validate-banks.cjs
node --test tests/engine.test.cjs
```

需要复现页面交互测试时再安装开发依赖：

```bash
npm ci
npm test
```

npm依赖只用于开发测试，不参与网页运行，不需要上传node_modules。UI测试使用DOM环境，覆盖选择、提交、计数、课程隔离、旧记录迁移；不等同于真实浏览器的视觉或排版测试。

## 数据

学习进度按“每道题最近一次提交结果”统计，正确率不是累计历史作答次数。X型草稿不入统计。清空浏览器网站数据会删除记录；不同设备不会自动同步。导出按钮可保存本课程JSON备份，当前无导入恢复按钮。
