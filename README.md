# 刷题小助手 · 预防医学

适用于 `Ryanisoda/Ryanisoda.github.io` 仓库根目录的 GitHub Pages 静态站点。
预期网址：https://ryanisoda.github.io/

## 上传与发布

1. 解压压缩包，将其中的 `index.html`、`assets`、`data`、`.nojekyll` 和本说明上传到仓库根目录。不要上传 ZIP 文件，也不要在仓库根目录再套一层同名文件夹。
2. 仓库 → Settings → Pages → Build and deployment → Source，选择 **Deploy from a branch**。
3. 选择存放这些文件的分支（通常为 `main`）和 **/(root)**，点击 Save。
4. 等待 Pages 部署成功后访问 https://ryanisoda.github.io/ 。如页面尚未更新，可强制刷新。

`.nojekyll` 是空文件；若系统隐藏了它，可在 GitHub 上新建同名空文件。本站目录和文件名不依赖 Jekyll，即使漏传也不影响现有页面运行。
如果仓库已经包含其他网站，根目录的同名文件会被替换，请先备份。若已配置自定义域名，以 Pages 设置显示的网址为准。

## 文件

| 文件 | 用途 |
| --- | --- |
| index.html | 网站首页，直接打开，不再二次跳转 |
| assets/style.css | 页面样式与手机适配 |
| assets/app.js | 刷题、搜索、错题本和统计功能 |
| assets/favicon.svg | 网站图标 |
| data/bank.js | 原始题库，共867道题 |
| .nojekyll | 禁用 Jekyll 构建 |

## 使用与维护

- 无需安装 Node.js、运行构建或配置服务器，不需要 WorkBuddy 分享码。
- 普通刷题、快刷、题型/章节筛选、选项乱序、搜索、标记、错题本与学习统计均在浏览器运行。
- 所有资源使用相对路径，无外部字体、CDN 或接口依赖。
- 学习记录保存在当前浏览器的 localStorage 中；清理网站数据会清空记录，手机和电脑不会自动同步。
- 原 WorkBuddy 站点和本站域名不同，原有记录不会自动迁移。当前“导出学习数据”用于备份查看，尚未提供导入恢复功能。
- 题库和答案会随前端资源公开。更新题库时应保留原有题目 ID，否则历史错题和统计可能无法对应。
- 可直接双击 index.html 预览；正式使用以部署后的 HTTPS 地址为准。
